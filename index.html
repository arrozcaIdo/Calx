Calx (.clx) Tokens & Lexemes Summary Reference

Complete formal reference of lexical classifications, reserved tokens, and DFA constraints

KEYWORD Reserved Control & Chemistry Keywords

Control structures, workflow decorators, HPC task configuration directives, and domain reaction declarations:

reaction theory task run compound contract if elif else for in print read range from import on_success on_failure is not and or scheduler cpus memory walltime
TYPE_SPEC Primitive & Container Types

Strict capital-case type specifiers for quantities and mathematical containers:

Float Integer Boolean String mol Vector Matrix
DIM_CLASS Physical Dimension Classes

Enforces dimensional analysis at compile-time when parametrizing containers:

Length Mass Time Temp Pressure Energy Amount Volume Dipole Data
UNIT Physical & Compound Units

SI and computational units recognized directly by the scanner without external library decorators:

Kelvin Celsius kg g mg m km cm nm Angstrom mol mmol L mL Joule Debye kJ kcal/mol kJ/mol Hartree eV s fs ps ns bar atm Pa GB MB
DURATION Walltime & Duration Literals

Durations use HH:MM:SS (for example, 24:00:00). Separate a numeric literal and its unit with whitespace, for example 100 mg.

ATTRIBUTE Unit Projection & Molecular Attributes

.to(...) must be contiguous; .formula and .molecular_weight are recognized as molecular attribute keywords. Single- and double-quoted f-strings, such as f"Formula: {sample.formula}", are emitted as one opaque FSTRING_LIT token; triple-quoted f-strings are not supported.

OPERATORS Chemical Reaction, Matrix & Assignment Operators
<=> Reversible stoichiometric chemical equilibrium
=> Forward stoichiometric chemical reaction
-> Index contraction mapping in tensor expressions
@ Matrix multiplication / coordinates rotation
+=, -=, *=, /= Compound assignment operators (COMP_ASSIGN)
==, !=, <=, >= Relational comparison operators (REL_OP)
^ Exponentiation operator (EXPONENT)
+, -, *, /, % Arithmetic operators (ARITH_OP)
STATE_FLAG Simulation Convergence Flags

Flags used to check geometry relaxation and electronic structure state:

converged stationary radical
NOISE_WORD Grammar Noise Words

Syntactic sugar for fluent execution syntax:

the Example: run the heavy_opt
# Lexical Analyzer (DFA) Invariants & Scoping Rules
Identifier Specification
  • Starts strictly with [a-zA-Z_].
  • Leading digits rejected: 1mol, 2x trigger LexicalError.
  • Hyphens prohibited: cell-mass triggers LexicalError.
  • Case-sensitive: Float is a type; float is an identifier.
Off-side Rule (Indentation)
  • Indentation must be exact multiples of 4 spaces.
  • Generates synthetic INDENT & DEDENT tokens.
  • Non-multiples of 4 (e.g. 2 or 3 spaces) raise an IndentationError.
  • Unaligned dedents matching no prior scope level throw an error.
